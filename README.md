🚗 Real Car — Oficina de Suspensão

Site institucional desenvolvido para apresentar os serviços da Real Car Amortecedores, especializada em recondicionamento de amortecedores e serviços completos de suspensão em João Pessoa – PB.

Projeto leve, moderno, responsivo e com foco em apresentar informações claras ao cliente e facilitar o contato rápido.

🔗 Acesse o site

https://lucasndf.github.io/site-realcar/

🧩 Tecnologias Utilizadas

HTML5
CSS3
Google Fonts (Inter)
Design responsivo
Links externos para WhatsApp e Google Maps

Nenhum framework — código limpo, direto e rápido.

🖼️ Estrutura do Site

O site contém as seguintes seções:

⭐ 1. Início (Hero Section)

Apresentação da oficina
Chamada principal
Botão direto para contato via WhatsApp

⭐ 2. Serviços
Grade com três cartões apresentando os principais serviços:
Recondicionamento de Amortecedores
Serviços de Suspensão
Troca de Peças

⭐ 3. Sobre
Pequena descrição institucional destacando confiança, experiência e especialização.

⭐ 4. Contato
Inclui:
Endereço com link direto para o Google Maps
Horário de funcionamento
Botão de WhatsApp estilizado e funcional

⭐ 5. Rodapé
Informações de direitos autorais.
